## 新增三点

| 点 | 验收要求与实现 | 边界 |

| 7. 日志层级 | runId / requirement / phase / session / request 或 call，统一 severity；阶段开始/结束和耗时，30 秒心跳。v4 正常工具也输出简明 INFO，stderr 同步人读行；心跳标注等待对象、当前命令和时长，错误/成功计数分开。 | 不额外建设日志 Web UI。会话中断不能猜成 OOM；记录 signal 和超时证据。活动不是业务通过。 |
| 8. 人民币费用 | 平台公开价目表、缓存感知估算、每请求/需求/阶段/会话累计；estimatedCny 与 billedCny 分离；缺失用量和缓存字段给下界/区间，不显示虚假精确金额。可配置费用/请求数限额。 | 正在执行/中断的请求可能收费；本地估算不能代替结算，限额不能保证精确账单上限。七天过期价目拒绝精确估算。 |
